# data-first-ui

一套「扫读优先」的界面语言。核心不是配色，是**让每一块信息都有一个视觉锚点**。

## 什么时候用

- 页面看起来「全是字」「很挤」「看不出重点」
- 一张卡片里有 4 行以上并列的「标签：值」
- 用户说不出哪里不对，只说「不好看 / 不显眼」
- 要新建列表页、详情页、看板页

**不适用**：表单录入页（那套规矩在 `packages/miniapp-ui/tokens.wxss` 里，「有底色=要你填」优先），
以及只有一两行内容的提示卡。

## 一条铁律

> **每张卡片有且只有一个视觉锚点。**

锚点 = 一个大号数值、一个状态胶囊、或一张缩略图。其余全是辅助，一律降到 26–28rpx 灰色。

违反它的典型长相（PMS 员工端工单卡改版前就是这样）：

```
工单编号  WO20260830-0007      ← 32rpx 黑
报修地址  枫桦景苑 17号 201室   ← 32rpx 黑
故障描述  厨房水管漏水          ← 32rpx 黑
报修时间  08/30 22:44 已等8天   ← 32rpx 黑
报修人    王女士                ← 32rpx 黑
```

七行一样重 = 没有重点 = 眼睛只能从第一行逐行读到最后一行。
改法不是调字号，是**挑一个锚点，把其余压下去**。

## 四个模式

按出现频率排序。每个都有可直接抄的实现，见 `references/patterns.md`。

### 1. 数据网格（stat-grid）— 最核心

把 4–8 个关键字段排成 2×N 网格，每格三层：

```
  标签      ← 26rpx  --color-text-tertiary
  C51       ← 44rpx  --color-brand  600  tabular-nums
  摆渡车     ← 24rpx  --color-text-tertiary
```

数值那一行是锚点。**标签和说明必须比数值小一半以上**，差距不够就退化成普通文字行。

什么该进网格：能用 1–4 个字/数字说完的（工号、房号、楼栋、时长、数量、状态）。
什么不该进：整句话（故障描述、备注）——那些留给下面的文字区。

### 2. 深色页头（hero）

页面顶部一块深色区（`--color-brand-dark`），承载页面标题 + 1–3 个关键统计。
白字，统计数字 48–56rpx。内容区用 `--radius-lg` 上翻圆角压在它上面。

用途：让「这一屏是什么、现在什么情况」在第一眼就说完。列表页尤其值得。

### 3. 状态胶囊（pill）

描边不填充，圆角拉满，语义色只上文字和边框：

```
待接单  蓝  |  进行中  品牌色  |  已完成  绿  |  超时  红
```

比色块温和，一屏出现十几个也不吵。填充色只留给**唯一的主按钮**。

### 4. 悬浮底栏（floating tabbar）

白色胶囊浮在内容上方，不贴边、不占满宽，带柔和阴影。
比贴边横条更轻，也让内容区看着更「有余地」。

## 层级只有三档

多于三档就会糊。定死：

| 档 | 字号 | 颜色 | 用在 |
|---|---|---|---|
| 锚点 | 40–56rpx / 600 | `--color-brand` 或 `--color-text` | 每块唯一的那个数值 |
| 主体 | 32–36rpx / 500 | `--color-text` | 标题、正文 |
| 辅助 | 24–28rpx / 400 | `--color-text-tertiary` | 标签、说明、时间 |

**不要**出现 30rpx 灰、32rpx 灰、34rpx 黑这种挤在一起的中间档——
那正是「页面全是字」的成因。宁可砍掉信息，也不要加第四档。

## 配色：留住 PMS 自己的品牌色

飞常准用亮蓝 `#2f7dfa`。**PMS 不跟**——物业场景要稳重，
`--color-brand: #31558a` 和 `--color-brand-dark: #243f69` 保持不变
（全局约定：品牌已有配色优先于任何设计参考）。

学的是**用色方式**，不是色值：

- 深色只出现在页头，不用于卡片
- 品牌色只上锚点数值和唯一主按钮，不用来上大面积底
- 语义色（成功/警告/危险）只上文字和边框，不填充
- **语义色一屏不超过 3 处**。品牌色不按处数算——网格里一排蓝数值是同一类元素，
  眼睛读成一个整体；真正会吵的是红黄绿散落各处。判断标准是「有几种颜色在抢注意力」，
  不是「有几个元素带颜色」。

## 落地前的自查

改完任何一屏，逐条对：

1. 眯眼看，第一眼落在哪？落在锚点上才算对
2. 一张卡里超过一个大号数值？删到只剩一个
3. 有没有第四档字号偷偷混进来？
4. 带颜色的元素超过 5 处了吗？
5. 触控目标 ≥ 88rpx、正文行高 ≥ 1.6 还守着吗？
6. 间距还在 8rpx 节奏上吗（`--space-*`，不写 10/12/22 这种随手值）

具体色值、字号、圆角、阴影和可直接抄的 wxss 片段，见
`references/patterns.md`。
