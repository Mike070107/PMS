# PMS 公寓小票打印助手 1.0.0

## 现场接入

1. 在接 XP-80C 的 Windows 电脑安装厂商驱动，确认存在全机可见的本地打印队列，并放入 80 mm 连续热敏纸。
2. 在 PMS 的「系统与设备 → 公寓小票打印机」登记打印机名称，生成 10 分钟有效的一次性绑定码。
3. 在打印电脑下载并运行本页的 Windows 助手。选择对应队列，输入绑定码，点「绑定并启动」。安装需要 Windows 管理员权限。安装后的 PmsReceiptPrinter 服务使用 LocalService，随系统启动，关闭设置窗口后继续接收任务。电脑需要能通过 HTTPS 访问 PMS。
4. 在设备列表展开打印机，勾选允许使用的员工。员工还须具有公寓收费查看权限和对应房屋的数据权限。收款后选择是否打印，也可在本户记录或今日明细上补打。

服务程序和受 ACL 保护的绑定配置位于 Program Files 下的 PMS/ReceiptPrinter。配置中的长期服务凭据由 Windows DPAPI 加密。更换打印电脑时，在 PMS 重新绑定可使旧凭据失效并取消待领任务。解绑时已经进入 Windows 队列的任务需在打印电脑核对。

## 出纸控制

每次取一张已保存收据，最多 20 个收费项目和 45 行折算纸长。收费单保存、打印申请和实际出纸分别记录或反馈。每次输出一个 RAW 队列任务、一份正文和一次切纸命令。驱动、机芯和刀头距离决定实物票尾留白。

相同原票只允许一次首次打印，补打带有「补打」标记。一次操作重复提交取回原任务。服务端按收据限制重复提交，服务端及助手分别限制每台每分钟 6 张。积压超过一分钟的待领任务失效。领取后失联时不重新派发，Windows 队列非空或报告异常时助手暂停领取。现场提交错误或发现异常频率后，核对出纸和系统队列，在助手窗口确认恢复。界面「已送入打印队列」表示 Windows 已接收任务。

## 构建及上线范围

用 Windows .NET Framework 4.x 运行 tools/receipt-printer/build.ps1。生成并自检的安装程序在 apps/neighbor-web/public/downloads/receipt-printer/PmsReceiptPrinter.exe。首次上线需按项目流程应用 1796700000000-ReceiptPrint 迁移、发布 API 和 Web，并上传员工小程序。当前构建使用 https://prsznh.cn/api/v1，绑定码和票据只发往该源。

现场验收应覆盖收款后取消、首次打印、本户与今日明细补打、断网后核对队列、撤权，以及 XP-80C 的中文、金额、切纸和票尾长度。
