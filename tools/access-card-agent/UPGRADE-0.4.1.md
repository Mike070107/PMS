# PMS 数据同步助手 0.4.1

本次修正停车旧库查询：

- 通过 `Car_Issue.Owner_ID` 自动识别并联查住户主表。
- 支持用车牌查住户，也支持用房号、姓名或电话反查车辆。
- 返回旧库车辆类别、住户编号、到期日、车位和住户主表原始字段，便于核对车辆身份。
- 查询仍为参数化只读 SQL，不开放登记、续期、换牌、注销或控制器写入。

升级步骤：

1. 退出右下角的 PMS 数据同步助手。
2. 解压本包，覆盖原目录中的 `Pms.DataSyncAssistant.exe`。
3. 双击程序并点击“保存配置并安装后台服务”；已有代理 ID、密钥和数据库密码会继续保留。
4. 网页显示版本 0.4.1 和“查询已就绪”后，分别用一个已知车牌和房号测试。

不要删除原目录中的 `agent.config.json`、`agent.token.dat`、`parking-db-password.dat`。
