# PMS 数据同步助手 0.4.0

## 本次更新

- 停车管理页可通过房号、住户、电话或车牌实时查询 `parking1` / `parking2` 的 `Car_Issue`。
- 查询只执行参数化 `SELECT TOP 50`，两个库合计最多返回 100 条，不调用任何写入存储过程。
- 兼容 `228/5/301`、`198-5-201` 等分隔格式；返回真实旧库列名，便于现场核对字段含义。
- 查询失败会自动重试，连续三次失败后在网页显示数据库返回的具体原因。

## 升级

1. 右键右下角 PMS 图标，选择“退出状态图标”。
2. 停止 `PMSAccessCardAgent` Windows 服务。
3. 用本包的 `Pms.DataSyncAssistant.exe` 覆盖旧程序。
4. 双击打开，点击“保存并安装后台服务”。
5. PMS 停车管理页显示“查询已就绪”后，用一个已知房号和车牌各查询一次。

升级不需要重新输入代理 ID、一次性密钥或停车数据库密码；保留原目录里的
`agent.config.json`、`agent.token.dat` 和 `parking-db-password.dat`。

本版本仍未开放停车写入、续期、换牌、注销或设备下发。
