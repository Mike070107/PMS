# 0.5.2 升级说明

本版增加固定服务身份、单项连接密钥和一键更新：

1. PMS 网页只生成一项“一次性连接密钥”，助手自动识别并固定代理 ID。
2. 固定服务轮换密钥时沿用原代理 ID，不再每次创建新身份。
3. 已配置目录会锁定服务用途，避免旧库同步和停车网关共用目录时覆盖配置。
4. 以后升级在旧助手中点“安装更新”，选择新版 `Pms.DataSyncAssistant.exe`。程序会停止服务、备份旧版、替换并重启；不会改动任何 `.json` 或 `.dat` 配置。

当前机器若曾把两个代理装进同一目录，被覆盖的那一个仍需做一次恢复。恢复后请分别固定在 `LegacySync` 与 `ParkingGateway` 目录，后续升级不再重填。
