# PMS 数据同步助手 0.3.0

## 本次更新

- 新增停车系统网关，可配置 `parking1` / `parking2` 双库并执行只读探测。
- 停车数据库密码使用 Windows DPAPI 加密，不写入 JSON 或日志。
- 修复重复双击或重复安装服务后出现多个右下角常驻图标：托盘与设置窗口现在都是单实例。

## 升级

1. 右键旧托盘图标，选择“退出状态图标”。如果已有多个，各退出一次；旧图标仅为通知区残影时，鼠标划过后会消失。
2. 用本包的 `Pms.DataSyncAssistant.exe` 覆盖旧程序。
3. 双击打开，点击“保存并安装后台服务”。
4. 连续双击应用或重复点击安装，右下角始终只能保留一个状态图标。

升级不需要删除 `agent.config.json`、`agent.token.dat` 或任何 `*-password.dat`。
