# PMS 数据同步助手 2.5.1

## 修复

- 新版 Windows 服务仍在运行时，不再因健康状态文件延迟而误卸载。
- 只有确认旧版服务已恢复运行后，才删除启动失败的新版服务。
- 没有可用旧服务时，保留新版服务注册并自动重试，不再留下“零后台服务”状态。
- 服务启动后前 2 分钟每 3 秒刷新一次健康状态，后续恢复为每 30 秒。

## 事故原因与验收

2.5.0 在新服务已发出 PMS 心跳时，仍可能因首份 `health.json` 早于连接完成而在 55 秒后误判失败。失败分支会先卸载新服务，再尝试启动可能已不存在的旧服务，最终留下新旧服务均离线。

回归自检固定覆盖三种决策：新服务正在运行时必须保留；旧服务存在时必须先验证恢复；旧服务不存在时必须保留注册并重试新服务。发布前执行 Release 构建与 `--self-test`。

## 安装

在助手中检查更新安装 2.5.1，或使用管理员 PowerShell 执行：

```powershell
.\Pms.DataSyncAssistant.V2.exe --install-service
```

连接配置和密码仍保存在 `ProgramData\PMS`，更新不会覆盖。
