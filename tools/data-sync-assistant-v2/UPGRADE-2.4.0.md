# PMS 数据同步助手 2.4.0

本版收紧停车查询范围，并补充真实换牌时间：

- `6/502` 只按 6 号楼 502 室查询，不再命中 36 号楼；兼容 `198/6/502`、`228/06/502` 和旧库卡序号后缀。
- 自动区分房号、完整车牌、4–6 位车牌尾号、7 位以上电话和住户姓名；过短的纯数字会直接提示补充信息，不会扫描整库。
- 旧库人员姓名字段若实际保存 `198-6-402`，会按房号返回。
- 换牌历史优先读取 `Up_Issue` 的真实换牌操作时间；旧记录没有可靠业务时间时明确显示“操作时间待旧库回传”，不再拿查询时间代替。

## 升级

1. 打开现有“PMS 数据同步助手”。
2. 展开“助手信息”，点击“安装 / 安全升级后台服务”。
3. 选择本包内的 `Pms.DataSyncAssistant.V2.exe`。
4. 等待进度显示完成；原有代理身份、连接参数和加密数据库密码会保留。
5. 回到 PMS 停车管理页点击“重新检测”，确认版本为 2.4.0，再用 `6/502` 和一个已知车牌各查询一次。

独立停车代理需升级到 0.8.0。旧版助手仍能保持心跳，但为避免宽泛查询，不再领取新的停车查询任务。
