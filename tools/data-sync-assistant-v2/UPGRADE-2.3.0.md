# PMS 数据同步助手 2.3.0

本版开放停车旧库住户资料的正式更新：姓名、电话、房号和备注可从 PMS 页面编辑，助手写入后立即读回核对，并在备注追加“操作来源：PMS系统”。

## 升级

1. 打开现有“PMS 数据同步助手”。
2. 展开“助手信息”，点击“安装 / 安全升级后台服务”。
3. 选择本包内的 `Pms.DataSyncAssistant.V2.exe`。
4. 等待进度显示完成；原有代理身份、连接参数和加密数据库密码都会保留。
5. 回到 PMS 停车管理页点击“重新检测”，确认版本为 2.3.0，状态显示“住户资料可编辑”。

若仍显示“住户写入未就绪”，请在助手中重新测试停车连接。账号必须同时具备旧停车系统车辆存储过程执行权限，以及 `Car_Issue.Owner_ID` 关联住户表的 `UPDATE` 权限。
