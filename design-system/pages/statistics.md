# 统计汇总：宽表与筛选抽屉专项约束

> 2026-11-10 用户截图明确覆盖通用内容限宽规则。仅适用于统计汇总，不改变其他业务页。

## 宽表区域

- 统计路由解除 Shell 内容容器的居中最大宽度，使用侧栏右侧全部可用内容宽度；保留正常页面内边距。
- 不以放大表格内部 `min-width` 代替解除父级限宽；2K/4K 不能在结果卡片两侧留下大块人为留白。
- 超宽数据只在表格容器内部横向滚动，页面自身不能横向溢出。保持已有固定列、金额语义和分页。

## 顶部悬浮筛选抽屉

- 各屏宽均从上方向下滑入；覆盖在结果内容之上，不从底部弹出。
- 用户进一步指定「抽屉卡片悬浮效果」：使用不透明主题卡片底色、16px 圆角及清晰的双层大范围投影；与顶栏/导航保留 16px 间距，不能贴边成为普通侧栏。阴影不得通过改变底层尺寸或缩放表格来伪造。抽屉专属规则必须高于 ERP 的 `#web .card` 优先级，防止大圆角和悬浮阴影被通用扁平卡片覆盖；其他卡片保持原样。
- 仅动画 `transform` 与 `opacity`，进入与退出均有动效，尊重 `prefers-reduced-motion`。
- 展开/关闭全过程中，下方目录、结果卡片及表格的 x/y/宽/高必须保持不变；禁止预留侧栏、推挤内容、改变占位、锁滚动造成横移。
- 筛选入口占位稳定、`aria-expanded` 准确；关闭态不可点击或聚焦。Escape、点击外部、收起及执行统计均走一致的关闭行为。
- 保留日期弹层的正常交互、筛选草稿及已应用查询快照，不改变金额口径。

## 按需生成与导出

- 首次进入只加载轻量筛选字典，不计算统计；浏览统计项目、修改条件/分组/页签、重新生成与错误重试均只展开浮动筛选卡片或修改草稿。
- 点击项目即选中目录并动效展开筛选；仅卡片底部「生成统计报表」提交查询快照。连续点击必须同步防重，查询期间保留草稿但不能重复提交。
- 等待时在视口中央显示快速旋转的品牌色加载环与「正在生成统计报表」，明确显示查询项目及耗时说明，不伪造进度百分比；尊重减少动态效果，不锁滚动、不挪动底层布局。
- 结果始终关联已提交快照，不随草稿改名；失败不得导出同类旧缓存。分页防重，重新生成后不得追加旧分页响应。
- 每次导出只生成一个真正的 `.xlsx`，仅包含当前成功结果的已加载行和本报表副表；不遍历目录，不补查接口。文件保留多级合并表头、合计、边框、数字格式、筛选及口径说明；未知仍为「—」，编号保留前导零，公式样文本作为安全文本。
- 浏览器自动验收禁止真实下载到用户 Downloads，以 CDP 禁止下载并捕获 Blob/anchor 检查一次单文件，避免测试污染用户下载列表。

## 验收

- 真实浏览器以正式页面、原样 CSS 与真实 Shell 父级层次验证；隔离合成 API 不代表生产验收。
- 覆盖 2886×1453（用户截图）、1920、1440、390、320；动画逐帧检查结果几何和滚动位置，不只比较首尾截图。
- 验证快速开关、退出动效、减少动态效果、日期弹层、等待/失败/成功；其他路由原有限宽不变。
