# PMS Admin design

## Existing authority

延续 `design-system/pms-admin/MASTER.md`、现有Ant Design组件和公共CSS。当前变更只重组物业费的任务流程，不改变全站品牌。

## 物业费查询

- Mode: Operate。
- 页面以明确的小区和房号选择开始；未选房号时显示选择提示，不先呈现全库账单或公寓收费工具。
- 选户后，房屋地址和住户是上下文，未收/已收账单金额是主要数值，逐项账期与状态用于核对。
- 历史明细使用表格，列按房号上下文→费用项目→账期→金额→状态→实际收款/退款日期排列；低频凭证、发票、备注放在展开明细。
- 账期和实际收款日期分别标注，不把预缴未来账期误写为未来发生的收款。
- 只读状态始终明确；故障时不显示伪造零金额或旧库替代值。查询中有等待反馈，错误保留所选房号和筛选。
- 窄屏选择项单列，汇总换行，表格在自身容器横向滚动，不让整页横向溢出。
