### 固定回归与证据边界

- 2026-10-02 “下发设备”报 `列名 is_nullable 无效`：已定位助手 `ProcedureParameters` 读取 `sys.parameters.is_nullable`，与已记录的现场 SQL Server 2008 R2 不兼容，失败在 `Add_DownloadCard` 执行前。2.5.18 改读旧版共有的四列参数元数据；不修改数据库结构，也不更改 `sys.columns.is_nullable` 的正常查询。可为 NULL 不等于输入参数可省略（[微软参数目录说明](https://learn.microsoft.com/en-us/sql/relational-databases/system-catalog-views/sys-parameters-transact-sql)），因此未知输入明确停止，不能靠默认 NULL 执行；同步修正类型、Unicode 字符长度和输出长度保留。自检用仅四列的 DataTable 验证解析和真实 SqlCommand 绑定、缺参拒绝。构建/自检通过不等于现场 SQL/设备回执通过；本机未取得现场连接凭据、共享路径不可访问，未执行真实下发。生产发布和现场升级另行记录。
- 2026-10-09 二期续期后为沪A950J6下发时报 `Add_DownloadCard 参数 @D_Stratime 无法从旧库车辆记录映射`：过程使用 `Car_Download.D_Stratime` 命名，车辆主表实际字段为历史拼写 `Car_Issue.Sart_Time`。助手现显式将 `D_Stratime`（兼容 `D_Starttime` / `D_Sarttime`）映射到真实 `Sart_Time`，并将 `D_Endtime` 映射到 `End_Time`；回归覆盖真实 `DateTime` 值，Release 构建及完整自检通过。尚未发布更新包、现场助手尚未升级，也未重新执行该车设备下发。

- `test:parking-owner`：漏车牌、同户多车定位、任务幂等/重试、回执证据等；`SelfTest.cs`：助手解析/数据库更新结构及升级基础用例。它们不等于真实 SQL/硬件成功。

### 2026-10-02 续期快捷期限按自然月月底（本地验证，未发布）

- 现象/根因：9 月 30 日选 1 个月得到 10 月 30 日。代码是 `add(months, 'month')` 保留日号，并非固定加 30 天；未执行目标月月底归整。
- 用户确认规则：原到期日所在月份顺延所选月数，取目标自然月最后一天；平年二月 28 日、闰年 29 日，大小月/跨年自动处理。正式弹窗初始值、切换期限及预览续期共用 `src/lib/parkingRenewal.ts`；仍允许手动选择日期，提交按所选日期，不修改金额规则、新增登记或其他操作。

## 2026-09-29 真实查询链路（历史）

- PMS 新增租户隔离的短期停车查询任务；管理员输入至少 2 个字符后，在线停车网关领取任务并回报结果。
- Windows 数据同步助手 0.4.0 同时查询 `parking1`、`parking2` 的 `Car_Issue`，只执行参数化 `SELECT TOP 50 ... WITH (NOLOCK)`，不调用写入存储过程。
- 查询兼容房号斜杠/横线形式，结果保留真实数据库列名；网页优先识别并紧凑展示车牌、房号、住户、电话、车位和统一到期日，其他字段可展开核对。
- 旧版 0.3.0 只支持数据库探测，网页必须显示“需升级助手”并禁用查询；0.4.0 在线且上报 `parkingDbRead` 后才显示“查询已就绪”。
- 任务租约 90 秒，失败最多重试 3 次；网页轮询约 72 秒后给出明确超时提示。每个库最多 50 条，接口总计最多接收 100 条、每条最多 60 个标量字段。
- 浏览器验收覆盖：0.3.0 升级提示与禁用态；0.4.0 就绪态；以 `228/5/301` 查询后展示车牌卡片和可展开的原始字段。
- 仍未开放登记、续期、换牌、注销或设备下发；页面“写入未开放”是能力边界，不是可点击按钮。
- 发布复核发现：为验证 0.3/0.4 两种状态而写在真实页面组件内的样例值，虽然生产不渲染，仍会进入生产 JS。根因是“开发路由受保护”不等于它传入组件的常量也会被剔除。已把全部验收数据迁到仅在 `import.meta.env.DEV` 下动态加载的独立页面；验收除检查界面不显示外，还必须扫描生产产物不存在样例房号、住户、车牌和车位。

## Windows 本地停车网关

- 复用 `tools/access-card-agent` 的“PMS 数据同步助手”，新增 `parking_gateway` 部署身份，不另造一套 Windows 程序。
- 可在图形界面配置 SQL Server、`parking1`、`parking2` 和数据库用户；密码使用 Windows DPAPI `LocalMachine` 加密保存。
- `--parking-probe` 对两个数据库执行只读探测：统计 `Car_Issue` / `Car_Download`，并检查已调研存储过程是否存在。
- API 支持注册 `parking_gateway` 并接收心跳。在专用停车任务队列落地前，停车网关只获得空任务，不会误领门禁旧库任务。
- 能力上报为 `parkingDbRead=true` / `parkingDbWrite=false`。登记、续期、换牌、注销和设备下载仍保持关闭，必须在真库只读探测与存储过程参数验收后逐项开放。
