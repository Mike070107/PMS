# 账单第4节增量交付

仅实现 `bills-redesign-spec.md` 第4节；沿用第3节待缴清单、账龄、8行续页的A5/A4版式、短信发送与回执。未修改停车、门禁、小程序或现场助手。

## 已确认统计口径

- 收款日期只取 `ZJ_SKRQ`，缺失/非法日期不回退更新时间，明确计数提示。
- 只匹配通知快照中的原MIS账单及责任对象；金额归因、原账单和户级封顶，部分回款不虚增缴清户。
- 批次生成日按北京时间自然日计算T+30（含第30天），同日无法判定时分先后。
- 重叠窗口归缴费前最近有效批次，排序及去重考虑所有授权批次，不受当前显示页和日期筛选影响。
- 统计以保存的批次快照为基准，不证明真实触达或催缴导致付款。

## 增量接口

- `GET /fees/mis/collections/effect`：汇总、批次分页、到户明细，窗口固定30天，非法日期/超限明确失败，不截断伪报完整统计。
- `GET/POST /fees/mis/collections/followups`：责任对象跟进、电话说明、还款承诺、争议/申请/投诉冻结及明确解除；写操作使用现有 `fees/edit`，读操作 `fees/view`，同时校验租户、小区与MIS管理处范围。
- 承诺保存原待缴账单快照；按MIS已缴原账核对履约。今日待跟进按未履约到期责任对象去重。时间线按责任对象投影到批次详情，明确为跨批次记录。
- 冻结截止日含当日，预览剔除并列明原因；确认生成时再次预览。历史批次出现冻结住户时拒绝登记打印/发送，要求重新预览，而非悄悄改历史快照。
- `POST /fees/mis/collections/:id/prints`：验证授权、纸张、页数和幂等标识，服务端从快照重算页数。A5一联一纸、A4两联一纸；登记完成后才调用浏览器打印，登记失败不打印。登记只能证明打印请求，不能证明实体纸张、投递或送达。
- 原 `/fees/mis/options` 增量返回已有 `CollectionSmsService.readiness`，页面展示真实 `reason`，未重建发送/回执通道。
